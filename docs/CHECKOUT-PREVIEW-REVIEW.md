## 저장과 배치 보존
- 미리보기는 별도 draft만 변경한다. 실제 가구·소유량·골드·재료·진행·원장은 변경하지 않고, UI 명령에서도 저장 시각을 갱신하지 않는다.
- 기존 가구 자동 이동·삭제·보관은 없다. 사용자가 명시적으로 보관한 가구도 적용 전까지 초안에만 남는다.
- 적용 직전에 원본 배치 지문, 영업 준비 상태, 겹침·다중 셀·입구·주방·계산 대기·좌석 접근을 다시 검사한다. 실패하면 원본 유지. 미확정 이동이 있으면 적용 불가.
- 미적용 기존 저장과 새 게임은 기존 계산대를 유지한다. 적용 선택은 지점별 interior에 저장한다. 자동 마이그레이션은 추가하지 않았다.
- 영업 중 이전과 진행 중인 선물 조리 중 미리보기를 막는다. 초안 중 구매·영업 시작 등 다른 엔진 명령도 막는다.
- 실제 사용자 세이브는 읽거나 수정하지 않았다. 복제 fixture와 새 격리 브라우저 저장만 사용했다.
