0. 너의 역할과 목표
너는 「연이의 아틀리에」(꿀꿀 운세 code-destiny 세계관의 게임 오리지널 외전, 모바일 세로형 카페 경영 게임)의 코드·에셋·UI 를 맡는다. 빌드 없는 ES module + Canvas 2D, 외부 의존성 없음. 실행 npm start → http://127.0.0.1:5280 (개발 모드 /?dev=1), 테스트 npm test.

이번 작업의 목표 8가지:

시작 테이블을 5개로 늘린다.
지명 접대(호스트)를 1년차 5월부터 연다. 5월 이야기에서, 빚을 갚지 못해 절망하는 토끼 자매 앞에서 연이가 "뭔가 떠올랐다!" 하고 네오를 빤히 바라본 뒤 카페에 호스트 바를 접목하는 흐름으로 진행한다.
「용과 같이 0」 물장사 아일랜드처럼, 접대 중 네오가 도움을 요청하면 플레이어가 알맞게 대응한다. 잘 대응하면 네오의 스트레스가 내려가고 손님 만족도가 오른다.
네오의 의상을 여러 벌 그리고, 월정석으로 해금하거나 이벤트로 얻게 한다. 갈아입기는 가게 안 드레스룸 화면에서 본격적으로 하고, 입힐 때마다 네오가 그 옷에 맞는 대사를 한다.
대화창은 캐릭터가 실제로 말하는 것처럼 말하기 스프라이트 시트(입 움직임·눈 깜빡임)로 연출한다.
아기자기하면서 code-destiny 세계관에 맞는 에셋을 하나하나 전부 그린다.
UI/UX 를 고급스럽게 다듬는다.
영냥이가 사냥터로 떠나게 되는 에피소드를 넣는다(3월 첫 순). 돈이 급한 상황에서 네오가 "검은 손들은 죽으면 월정석을 떨어뜨리는데, 이게 꽤 가치가 있어!"라고 말하자, 연이가 네오를 억지로 사냥터에 보내는 코믹한 장면이다. 네오는 평소 사람 모습이고, 사냥터에 갈 때만 영냥이로 변신해서 간다.

2. 반드시 지킬 것 (기존 규칙 + 이번 작업 규칙)
기존 규칙
UI 는 dispatch(state, cmd) 만 부른다. UI 가 금화·지명 시간·영입 상태·의상 보유·스트레스를 직접 바꾸지 않는다.
정규 영업 1,800초, 지명 잠금 300초, 사냥 180초는 줄이지 않는다. 빠르게 볼 때는 개발 모드 배속을 쓴다.
개발 기능은 일반 화면·정상 저장과 분리한다.
저장 초기화는 사용자가 직접 고르고 확인했을 때만 한다.
오프라인 수익을 임의로 지급하지 않는다.
난수는 state.rng 로만 뽑는다. Math.random() 은 깜빡임 같은 화면 연출에만 쓴다.
보상·해금은 원장(ledger) 키로 한 번만 지급한다.
원작 보호
원작에 없는 동료의 이름·외형·성격·능력치를 만들지 않는다.
미정 캐릭터를 데스티노바 멤버로 소개하지 않는다.
네오의 진짜 이름·회귀자 설정·결혼 이야기는 다루지 않는다.
청토끼·서한비·윤달의 결말은 쓰지 않는다.
"박지은"이라는 이름은 쓰지 않는다.
호스트 바, 스트레스, 의상, 드레스룸, 새 대사·이야기는 모두 게임 오리지널 임시 설정이다. docs/WORLD.md 2절에 적고, 화면에서 원작 사실처럼 소개하지 않는다.
네오와 영냥이가 같은 인물(영냥이 = 네오의 고양이 모습)이라는 것은 원작 사실이다(WORLD.md 1절). "평소에는 사람 모습, 사냥터에 갈 때만 영냥이로 변신"이라는 규칙과 사냥터 출발 에피소드는 게임 오리지널이다.
연이는 일하지 않고 계산만 한다. 주방은 루나 언니, 홀은 루나가 맡는다. 연이는 계산대에서 지시·판단만 한다.
확정 규칙 보호
NEO_STATS 는 사용자 확정이다. 의상·음식·피버·스트레스로 바뀌지 않는다.
만족도 공식 H0 = M + 대화 보정 − 지명 대기 불만과 대화 보정 범위 ±5(RULES.TALK_BONUS_*)는 넓히지 않는다. 손님 만족도는 이 범위 안에서 오르게 한다.
RULES 의 값을 바꾸는 것은 아래 3절 A 의 TABLE_COUNT 하나뿐이다. 이것은 사용자 결정(2026-10-25) 이므로 주석에 그렇게 적는다.
범위 밖
로그인, 결제, 가챠(무작위 뽑기), 광고, 멀티플레이, 앱스토어 배포. 의상은 정해진 값으로 사거나 정해진 이벤트로 얻는다. 무작위 획득은 넣지 않는다.

B. 5월 호스트 바 개시 이벤트
지명 잠금

호스트 바가 열리기 전(3·4월)에는 지명 요청이 생기지 않는다. 손님은 모두 일반 식사를 한다.
이 기간에 네오는 접대하지 않는다. 가게에서는 입구 안내 연출만 하고, 이 연출에는 수익·능력치 효과가 없다. 밤의 영냥이 사냥은 그대로다.
열림 여부는 상태 플래그(예: state.hostbar = { open: false, openedDay: null })로 둔다.
5월 이야기를 본 순간 엔진 명령으로 한 번만 연다(story.seen 처리에서 ledger.story.m2 와 함께).
건너뛰기로 넘겨도 열린다.
저장 이전(migration)
이미 5월 이후인 기존 저장은 열린 상태로 불러온다.
3·4월 저장은 닫힌 상태로 불러온다.
persistence 테스트를 추가한다.
acceptCheck 와 손님 생성 쪽에 "호스트 바 개시 전" 이유를 넣는다. HUD·지명 버튼에도 이 이유가 보이게 한다.
지명 요청 확률(NOMINATE_CHANCE)은 열린 뒤에만 적용한다.
지명이 처음부터 열려 있다고 가정한 기존 테스트는 준비 단계에서 플래그를 켜게 고친다. 주석은 "테스트 준비".
프롤로그

네오가 첫날부터 접대·지명 5분을 말하는 대사를 바꾼다. 3·4월에는 홀 안내와 밤 사냥을 돕는다는 정도로만 쓴다.
영냥이 → 네오 변신 장면과 말투(부드러운 반말)는 유지한다.
프롤로그 끝의 네오 대사 "밤에는 다시 고양이로 강가에 나가 볼게. 검은 손들이 월정석을 물고 다니거든."과, 이어지는 루나 언니·루나의 환전·저울 대사는 아래 B2 에피소드로 옮긴다. 월정석과 사냥터 이야기는 B2 에서 처음 나와야 한다.
마지막 sys 안내에서 "월정석 환전소" 언급도 빼고 B2 의 sys 안내로 옮긴다.
m2(5월) 이야기 재구성

기존 「언니의 괜찮아요」 박자를 살리면서 아래 흐름으로 쓴다. 대사는 한 번에 두 문장 이하로 쓴다.

마감 후 장부. 연이가 계산해 보니 이대로는 만기까지 빚을 다 못 갚는다.

B2. 영냥이 사냥터 출발 에피소드 (3월 첫 순)
언제 나오나

새 이야기 id ev:hunt. 1년차 3월 상순 첫 영업 준비 때, 3월 달 이야기(m0) 바로 뒤에 한 번 나온다.
pendingStory 순서는 달 이야기 → 이벤트 에피소드(ev:*) → 인연 이야기로 한다.
calendar.markStory 의 id 정규식(지금 m<번호>·ending:·bond: 만 받음)이 ev:<영문 소문자> 형식도 받도록 넓힌다. 잘못된 id 는 지금처럼 거절한다.
이 에피소드를 보기 전에는 사냥이 잠긴다(huntCheck 이유: "아직 사냥터 이야기를 보지 않았습니다"). 첫날 바로 나오므로 실제 플레이 흐름은 줄지 않는다.
열림은 엔진 명령으로 한 번만 한다(story.seen 처리에서 ledger.story['ev:hunt'] 와 함께). 건너뛰기로 넘겨도 열린다.
저장 이전: 첫 순을 이미 지났거나 사냥 기록이 있는 기존 저장은 열린 상태로 불러오고, 이 에피소드를 중간에 다시 틀지 않는다.
새 게임에서 바로 hunt.start 를 부르는 기존 테스트는 준비 단계에서 열림 처리를 하게 고친다. 주석은 "테스트 준비".
흐름 (코믹하게, 대사는 한 번에 두 문장 이하)

네오가 아무렇지 않게 말한다. 강 건너 달그늘에 검은 손들이 있는데, "걔네는 쓰러지면 월정석을 떨어뜨려. 이게 꽤 가치가 있어!"
루나 언니가 저울에 달면 골드로 바꿔 줄 수 있다고 하고, 루나는 저울 담당을 자처한다(프롤로그에서 옮겨 온 대사를 여기에 쓴다).
연이가 네오를 빤히 바라본다. 초상화 표정과 반짝임 효과로 연출한다. "…네오. 방금 '꽤 가치가 있다'고 했지?"
네오가 당황한다(flustered). "어, 응… 근데 거긴 밤이고, 검은 손이 꽤 많—"
연이가 네오의 등을 떠밀어 문밖으로 보낸다(흔들림·효과선 연출). 행동력 쪽지나 도시락 봉투를 쥐여 줘도 된다.
연이 괄호 속마음 예: "(직원 복지 별 하나. 대신 매출은 별 다섯 예정.)"
강요는 웃음 포인트로만 쓴다. 때리거나 위협하는 장면으로 만들지 않는다.
네오가 한숨을 쉬고 수락한다. "…알았어. 대신 이 모습으로는 못 싸워."
모자의 초승달 빛이 번지며 네오가 영냥이로 변신한다(프롤로그 변신의 반대 방향, 같은 금빛 연출). 초상화를 neo → neo_cat 으로 바꾼다.
영냥이: "다녀오겠다." 같은 무표정 해라체 한마디로 마무리하고, 연이가 한 줄 받아친다.

사냥은 영업 준비 중에 마을 → 달그늘 사냥터에서 떠난다. 3분, 행동력 1.
