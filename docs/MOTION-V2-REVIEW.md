## 원본/압축 근거
모션 ZIP3개는 정상 ChatGPT 앱 첨부 다운로드로 수신하여 D:/yeoni-qa/art/cafe-ux/motion-v2에 별도 폴더로 추출했다. 기존 credential helper는 재시도하지 않았다. ZIP 원본 유지·CRC/경로 검증. SOURCE_QA/metadata/sprite_manifest의 비균등 rect를 사용했다.

기존20개 시트 해상도 유지/q84/알파17단계 최적화와 구 조리시트 교체. 기존21개 파일은 before-runtime-integration에 복사 후 SHA256 일치 확인. 비교이미지는 budget-trial/comparison.jpg, 백업해시는 before-runtime-integration/hashes.json. 기존20시트 합성 PSNR최저36.74dB, 신규시트37.99dB 이상. 수치만으로 판정하지 않고 피부·얼굴/옷/배경 합성 비교를 직접 열었다. 원본을 삭제하지 않았다.

## 보류와 한계
입구 계산대 자동 마이그레이션은 자동 승인 검토에서 실행 전에 거절됐다. 기존 저장 가구를 자동 재배치하거나 보관 처리하는 위험이 사전 검증되지 않았다는 이유다. 동일 작업 재시도/우회 없음. layout/space/save 변경 없음, 사용자 실제 저장을 읽거나 바꾸지 않았다.

읽기 전용 fixture 분석: 기본5테이블/확장 예시는 충돌0, 계산구역에 테이블을 둔 예시는 테이블+의자2개 충돌. 모두 원본 상태 동일, 보관0. 경로검사는 입구→계산대/연이/픽업/좌석 연결 확인. 이것은 실제 사용자 저장을 안전하게 자동 이전할 근거가 아니다.

비파괴 대안은 설계만: 기존 저장의 layoutVersion/배치를 유지하고, 준비 화면에서 복제 draft에 새 계산 구역을 미리보기→충돌 목록 표시→수동 재배치→명시 확인 때만 적용. 취소는 원본 그대로. 새 게임 기본배치 변경과 기존 저장 전환을 별도로 구현해야 한다. 현재 코드에는 자동 이전도 이 새 미리보기도 적용하지 않았다.

원화 한계: 일부 걷기 반대발 교대/뒤쪽 닦기 숙임이 약하다. 모든 방향/옷 변형의 손-테이블 접점을 장시간 실제 영업으로 검증한 상태는 아니다. 실제 휴대폰 미검증. 새 화면 레이아웃/새 타이틀/지도 등 다른 승인대기 작업은 이번 모션 완료로 묶지 않는다.
