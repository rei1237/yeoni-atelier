# 연주곡과 첫 장부

## 확인한 문제
운영 프롤로그에서 `오 년. 서두르다가 네 몸부터 갚아 버리지는 말고.`와 이전 문장을 직접 확인했다. 전날 통합은 최신 1억 골드·인연·접대 규칙을 보존했으나 프롤로그 재교정은 충분하지 않았다. 별도 이야기 브랜치는 12만 골드·5분 접대 등 과거 조건을 포함하여 그대로 덮어쓰지 않고 현행 프롤로그를 수정했다.

## 수정한 파일·의도
- `src/story/prologue.js`: 74→98비트. 계약서 확인, 연이가 함께하기로 결정하는 과정, 직원 역할 분담, 모카와 첫 지출을 정리하는 대화를 보강했다. 단편적인 질문·부자연스러운 비유·상황이 이어지지 않는 서술을 정리했다. 꽃돼지 도입과 네오 변신은 유지한다. 기간 안내는 `TEMP.CALENDAR`에서 읽어 현재 24개월을 표시한다. 빚 안내는 기존 `TEMP.INITIAL_DEBT`를 사용한다.
- `src/ui/audio.js`: 대기 기본곡 Gentle Oriental Girl, 월드 기본곡 Crystal Garden. 둘 다 원본 저장소의 연주곡 허용 목록과 파일 매핑 확인. 첫 사용자 입력 후 시작하며 저장된 음소거·음량은 유지한다. 타이틀·월드·카페 수동 선곡은 따로 기억한다.
- `src/ui/app.js`: 월드맵을 별도 음악 장면으로 연결하고 음악실을 열어도 타이틀·월드 장면을 유지한다.
- `tests/audio-controls.test.mjs`, `tests/prologue-resume.test.mjs`: 첫 입력, 장면 전환, 수동 선곡·음소거 보존, 현행 기간·빚 안내를 검증한다.
- `docs/AUDIO-SFX.md`, `release.json`: 선곡 근거와 배포 버전 기록.

## 유지한 영역
결제·가격·인증·API·DB 변경 없음. 게임 진행 기간·빚·보상·영입 조건과 저장 구조도 변경하지 않았다. 이미 프롤로그를 본 저장에 강제로 다시 재생하지 않는다. 대기 화면의 `처음 만나는 이야기`에서 새 대사를 볼 수 있다.

## 검증
- `npm test`: 431/431 통과.
- `git diff --check`: 통과.
- 전용 Chrome 신규 세션에서 첫 입력 전 정지, 입력 후 대기 연주곡 재생, 실제 섬 이동 버튼을 통한 월드 연주곡 전환, 음악실 유지, 음소거 정지를 확인했다. 음악 재생 시각이 실제로 증가하고 스트림 길이도 읽혔다.
- 모바일 프롤로그 98비트를 첫 장면부터 마지막까지 진행하며 가로 넘침·대화창/조작 버튼 겹침을 확인했다. 실제 휴대폰 스피커 청취는 수행하지 않았다.

## 추가 확인
브라우저 정책 때문에 첫 클릭·터치·키 입력 전에는 소리가 나지 않는다. 기존 음악 끔 설정은 유지되므로 필요한 경우 음악 켜기를 누른다. 수정본은 새 게임 또는 대기 화면의 이야기 다시 보기에서 확인하며 저장 초기화는 필요 없다.
