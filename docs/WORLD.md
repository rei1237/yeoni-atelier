## 2. 이 게임이 정한 것 (2026-10-26 최신 사용자 결정)

다음은 원작의 확정 사실이 아니라 사용자 요청으로 만든 외전 설정이다. 초기 PDF·이전 구현과 충돌하는 시간·경제·역할은 이 절과 현재 코드를 우선한다.

- **인수 빚과 월급**: 새 게임 원금 99,999,999G. 이전 저장의 원금은 강제 인상하지 않는다. 인수 빚 월 2%, 청토끼 운영 대출 월 8% 복리. 창업 동료 네오·루나·루나 언니는 무급, 신규 영입자는 근무 순 비례 정액과 매출 성과급을 월말에 받는다. 전부 게임 속 수치이며 실제 서비스 결제·월정석 정책과 관계없다.
- **연이의 역할**: 사람 모습의 연이는 계산대에서 손님을 빠르게 결제한다. 준비 시간에는 꽃돼지로 농장을 직접 가꾼다. 씨앗·물·돌봄·날씨·계절·온실·농장 레벨과 수확 요리는 외전 시스템이다.

## 3. 참조 작품과 경계

Cookie Shop·아이러브 커피의 주문/꾸미기, Persona의 선택지 인연, 용과같이 0 물장사 아일랜드의 손님 등급/팁/피버, Stardew Valley·천수의 사쿠나히메의 계절/돌봄 개념을 참고했다. 해당 작품의 이미지·음원·대사·코드는 복제하지 않았다. 사용자 첨부 그림과 Code Destiny 자산의 재사용 범위 및 AI 생성 기록은 ASSETS.md·art-prompts.json·art-generation-log.json에 남긴다.

### 부탁 노트의 짧은 사연(게임 오리지널)
기존 퀘스트 목표에 맞춰 루나의 첫 접시, 연이의 첫 영업 장부, 청토끼의 상환·환전 안내, 모카의 밤이슬 맛 평가, 영냥이의 월정석 수량 확인, 무성의 새 좌석, 루나 언니의 특별 메뉴, 네오의 새 동료 맞이를 적었다. 원작의 새 사건이나 관계를 확정한 내용이 아니다. 완료 후 문구는 기존 quest 보상 원장과 수령 기록에 연결하며 추가 보상이나 별도 해금을 만들지 않는다.

### 재성의 섬 지도 참조
원작 EP.13–16의 항구·시간 거래 시장·언덕 빵집·중앙 시계탑과, 원작 `jae` 그림의 청토끼 비행선·금빛 부유 도시를 참조한다. 지도 위 카페·공방·농장 등 게임 목적지는 외전의 기존 설정이며 원작의 지리적 위치를 확정하는 지도는 아니다.

### 카페 지점과 주변 꾸미기(게임 오리지널)
