## 2. 이 게임이 정한 것 (2026-10-26 최신 사용자 결정)

다음은 원작의 확정 사실이 아니라 사용자 요청으로 만든 외전 설정이다. 초기 PDF·이전 구현과 충돌하는 시간·경제·역할은 이 절과 현재 코드를 우선한다.

- **다섯 해의 카페**: 1년차 3월부터 60개월·180순을 운영한다. 영업 한 순은 10분, 모든 지명 접대는 60초. 1/2/3배 가속은 카페 영업에만 적용하며 도움 요청·수동 조리 선택 시 1배로 돌아간다. 5월 「오늘부터 호스트 카페!」 개장 이야기를 마쳐야 지명·피버가 열린다.
- **인수 빚과 월급**: 새 게임 원금 99,999,999G. 이전 저장의 원금은 강제 인상하지 않는다. 인수 빚 월 2%, 청토끼 운영 대출 월 8% 복리. 창업 동료 네오·루나·루나 언니는 무급, 신규 영입자는 근무 순 비례 정액과 매출 성과급을 월말에 받는다. 전부 게임 속 수치이며 실제 서비스 결제·월정석 정책과 관계없다.
- **연이의 역할**: 사람 모습의 연이는 계산대에서 손님을 빠르게 결제한다. 준비 시간에는 꽃돼지로 농장을 직접 가꾼다. 씨앗·물·돌봄·날씨·계절·온실·농장 레벨과 수확 요리는 외전 시스템이다.
- **루나 자매와 모카**: 루나 언니는 주방, 루나는 홀 서빙·정리. 모카는 사용자 확정 **여성 수달**, 식재료·긴급 배달·무기·강화·회복 물품을 담당한다. 모카 친밀도에 따라 새 소모품이 열린다.
- **청토끼 금융 센터**: 월정석 환전과 골드·월정석 상환, 운영 대출을 맡는다. 빚을 모두 갚고 1,000,000G 이상을 모은 뒤 “돈 많은 게 주인님”이라며 영입 가능한 직원이 된다. 외모 2·화술 10, 담당 접대 매출·팁 +35%는 게임 창작 수치다.
- **손님과 공간**: 검소·평범·통큰·대부호 손님, 테이크아웃, 분위기를 보고 오는 손님, 인기와 새 동료 소문 대사. 카페 레벨에 따라 입장·메뉴·객단가가 성장한다. 소박한 카페에서 장식과 증축으로 분위기를 높이며 최대 20×24 공간·24테이블로 확장한다. 대부호가 만족한 지명 접대는 큰 팁과 피버를 유발한다.
- **음식과 판매**: 일반 손님은 기본 메뉴 위주, 높은 등급은 복잡한 메뉴를 선호한다. 운명 찻집 최고급 6종은 사냥 전용 재료를 사용한다. 미리 조리할 수 있지만 **지명 수락을 한 손님에게만 판매**한다. 지명이 조리 해금 조건인 것은 아니다.
- **네오와 영냥이**: 카페에서는 인간 네오, 사냥에서는 흰 마법 고양이 영냥이. 무기 선택 레벨은 매 사냥 새로 시작하고 탐사 경험치는 계속 축적된다. 탐사 성장과 영구 강화는 원작의 전투 서열을 뜻하지 않는다.
- **서한비**: 사용자가 첨부 모습으로 확정한 검은 드레스의 여성 인간형·붉은 눈의 검은 호랑이. 첨부 파일 안의 ‘마스터’/‘박지은’ 이름 대신 게임에서는 서한비로 사용한다. 영입 전 동료 화면에는 이름 대신 ?와 실루엣. 2년차 이후 농장 Lv.5·네오 인연 180·5분 생존·보스 3회 처치 조건의 히든 초대장으로 영입한다. 영냥이보다 강한 별도 사냥꾼이다.
- **생존 사냥**: 제한 시간 없이 쓰러지거나 귀환할 때까지 진행한다. 100단계, 35단계 청토끼 무리·55단계 변이 청토끼·85단계부터 흑월의 파편. 흑월의 파편은 최상위 영역의 매우 강한 잡몹이다. 생존 시간에 따른 추가 월정석·재료 보상, 캐릭터별 상한 없는 강화는 게임 창작이다. 원본 killerflowerpig의 풀·조이스틱과 전투 설계 개념을 참고했으며 라이선스·출처는 REUSE.md.
- **5년에 걸친 인연**: 윤달·모카·무성·서한비와 DEST1NOVA 동료의 영입·선택지 대화·특화 능력·인연 스킬은 외전 창작이다. 선택지에 따라 친밀도 +12/+6/+2, 단계 40/100/180/280에 능력이 열린다. 모든 성격·프로필이 공식 원작에서 확인된 사실이라고 주장하지 않는다.
- **DEST1NOVA**: 이름·상징은 SOLV THE WOLF, BAMBI THE PANDA, NEO THE LION, LUNE THE RABBIT, RAVEN THE PANTHER. 사용자가 제공한 최신 단체 일러스트 **가운데는 네오**. 포지션·개별 프로필은 사용자 요청 창작이며 정본 데이터는 dest1nova-profiles.js. 네오와의 인연을 계기로 솔브 2년차·밤비 3년차·루네 4년차·레이븐 5년차에 합류한다. 원작의 관계 모티프를 빌린 새 장면이며 소설 원문을 복제한 회차가 아니다.
- **드레스룸**: 남성 호스트 전용. 네오와 DEST1NOVA의 무대복·평상복·연미복·수영복 및 윤달·무성의 개별 의상. 의상은 외형·대사만 바꾸고 고정 접대 만족도 공식을 바꾸지 않는다. 선택한 의상 치비는 카페에서 그대로 사용한다. 서빙·정리에는 방향별 투명 소품과 실제 주문 메뉴 그림을 합성한다.
- **연출**: 대화 초상화는 정적인 라이트노벨 일러스트, 이동 치비는 네 방향 고정 셀. 주방·배달·퀘스트·기타 안내는 각각 루나 언니·모카·꽃돼지 연이·영냥이. 성공·실패 도움 반응도 꽃돼지·영냥이 그림으로 표시한다. Code Destiny 공개 OST와 자체 합성 효과음을 사용하며 음악은 사용자가 켠 뒤 재생한다.
