## 남은 검증과 제한

- 실제 Android/iPhone, 보조기기, 장시간 운영·100단계 전체 경제/사냥 밸런스는 미검증이다. 18회 봇 시뮬은 특히 초반 적을 회피하는 경로 편향이 있어 완성된 난도 근거가 아니다.
- 지도1536×1024 정본은1920/DPR2에서 물리 픽셀 확대가 생긴다. 존재하지 않는4K 정본을 만들었다고 하지 않는다.
- 모든 UI 데이터 조합·모든 언어/OS 글꼴·모든 의상 조합의 무한 전수 검증은 아니다. 검사한 화면·저장·해상도 범위를 JSON에 명시했다.
- 최근 사용자 첨부 Library PNG는 알려진 자격증명 접근 거절 때문에 소비 환경에서 직접 열지 않았다. 공개 정본/현재 로컬 파일과 사용자 전달 원본만 사용했다.
- QA의 Library 업로드 ID는 새로 생성하지 않았다. 이전 credential helper 거절을 유지하고 우회하지 않았다. 캡처는 D 경로에 준비했다.
- 최종 읽기 전용 git --work-tree diff는 OS Permission denied로 실패하여 재시도하지 않았다. 이번 회차 커밋/외부 게시 없음. 로컬 파일 수정·테스트·캡처 결과와 Git 상태 확인 실패를 구분한다.
