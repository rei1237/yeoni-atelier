## 설계 — 6-1 경고·통첩·배드 엔딩
- 상태: `state.creditor = { warnings:0, ultimatum:null|{ fromMonth, dueMonth, target, startRepaid }, lastCheck }`. 새 저장·이전 저장 모두 0부터(소급 벌칙 금지)
- 판정 시점: `chargeInterest` 직후(하순 마감) 같은 원장 키 `m<idx>` 안에서 한 번. 기록은 `ledger.creditor['m<idx>']`
- **마일스톤**(TEMP, 인수 빚 원금 `startingDebt` 대비 누적 상환): monthIdx 5(6개월) 10% · 11(12개월) 35% · 17(18개월) 65% · 23(24개월) 100%. 달성하면 `ledger.rewards['milestone:<idx>']`로 다음 달 이자 감면(예 50%, TEMP) 한 번
- **경고**: 그달 `added>0`(이자 미납) 또는 마일스톤 미달 → 경고 1단계 장면 `warn:<idx>`(청토끼 짧은 장면). 다음 하순에도 같은 상태면 → **통첩**: `target = 지금 상환액 + (TEMP) 원금의 x%`, 기한 3개월(9순). 금융 창·상단 HUD(`cafePanel`, src/ui/hud.js)에 "청토끼 통첩 · ○○G 더 갚기 · N순 남음"
- 기한 안에 목표 달성 → 통첩 해제 장면, `warnings=0`. 기한 넘김 → `calendar.ended=true, endingId:'bad'`(advanceTurn과 같은 경로, `gameEnded` 이벤트 1회). 마지막 순 결산에서 빚이 남아 있고 통첩 중이어도 `bad`로 판정할지는 `decideEnding`에 규칙으로 고정
- **배드 엔딩 이야기**: `ENDINGS.bad`(src/story/months.js:145). 연이와 동료가 가게를 내주는 결말. 청토끼 자신의 결말은 쓰지 않는다
- **크레딧**: 새 전체 화면 컴포넌트(아래→위 스크롤). 출연(동료 이름)·음악(src/data/music-catalog.js의 크레딧)·제작. 건너뛰기 버튼, 끝에 "다시 시작" 안내. `endingDialog`(src/ui/sheets.js:577)·`ENDING_HINT`(571)에서 연다. 정상 결말도 같은 크레딧을 쓸 수 있으면 좋다
- 배드 엔딩 뒤 선택지: "새 게임"(저장 삭제 없이 새 슬롯 시작 — 지금 새 게임 흐름이 저장을 덮는지 먼저 확인하고, 덮는다면 확인 대화) · "결말 다시 보기". **후일담 자유 영업은 막는다**(결정, WORLD.md에 기록)
- 필수 테스트: 미납 1회 → 경고 1회 / 연속 → 통첩 / 기한 내 상환 → 해제 / 기한 초과 → `bad` 1회 / 저장·복원 후 중복 없음 / 이전 저장은 즉시 배드 엔딩 없음 / 인상·네오 능력치 1회씩 / 옛 180순 저장은 2% 고정

## 함정
- `node -e`에 `${}`가 들어가면 bash가 "bad substitution". 스크립트는 `<<'EOF'` 헤어독으로 scratch 파일에 쓴다
- QA 저장에는 튜토리얼 id 전부를 본 것으로 넣어야 클릭이 오버레이에 막히지 않는다: delivery batch firstday firstdayintro opening personal signatures growth world branches staffing recipe finance expand shelter quests kfp trail shop cook serve catcafe music huntmusic worldcast host farm hunt armory outfits bonds decorate bondtalk. `page.setDefaultTimeout(4000)`
- headless에서는 게임 시간이 느리다. 무대 같은 시간 연출은 5~10초 기다려 찍는다
- `deserialize`는 `{ok,state}`를 돌려주고 영업 중이면 일시정지 상태로 연다(테스트는 `resume` dispatch)
- 저장 키 `yeoni-atelier.save.v1`
- 무대 금화 비는 캐릭터에 가려지지 않도록 `cafe-view.js`에서 pieces 다음 오버레이로 그린다(`stageRain`)
