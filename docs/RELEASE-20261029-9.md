# 달빛 수첩과 다섯 결말

## 통합
- 운영 611cd5b 위에 카페 브랜치 a27af42~c6fa760의 미배포 6개 커밋을 통합했다. 직원 대화, 영업 중 섬 이동 제한, 자동 팁, 분야별 MVP, 달빛 운세 수첩과 수첩 타일을 포함한다.
- 0efbb70 이야기 브랜치는 이전 기반의 12만 골드·옛 인연 단계·5분 접대·루나 환전소를 전제로 하여 전체 병합하지 않았다. 기존 프롤로그, 선택지, 현재 수치와 새 영입 조건을 유지하고 청토끼·연이의 장부 개그와 모카 배달 대사만 현재 구조로 옮겼다. 원본 브랜치는 보존했다.

## 수정한 파일과 의도
- `assets/illustrated/talking/yeoni_pig.webp`: 둘째 표정의 중복 눈썹만 교체. 33×30 영역 내 가시 픽셀 865개 변경, 밖의 가시 픽셀 변경 0. 1280×384·알파·입 모션 유지.
- `assets/illustrated/backgrounds/host_opening.webp`, `ending_{grand,clear,close,extend,bad}.webp`: 내장 image_gen으로 개별 생성한 6장. 960×640 WebP로 내보내고 원본 PNG는 작업 산출물에 보존.
- `src/story/months.js`, `src/render/asset-updates.js`, `assets/manifest.json`: 실제 호스트 개업 장면과 모든 엔딩의 첫 장면·마지막 장면에 연결. 필요한 이야기에서 로드한다.
- `src/ui/sheets.js`, `cafe-ux.css`: 결말 화면에 원화, 접근 가능한 제목, 모바일 스크롤·안전 영역과 긴 문자열 처리를 추가.
- `src/ui/fortune-sheet.js`, `src/data/fortune.js`: 기존 운세 안내 그림을 수첩에 연결하고 날짜 풀이의 한계·경계일·선택 저장 안내를 명확히 했다. 확정형 타로 표현을 성찰·행동 조언으로 바꾸고 미래 생일은 풀이하지 않는다.
- `docs/art-prompts.json`, `docs/ASSETS.md`: 생성 도구·프롬프트·규격·눈썹 변경 범위 기록.

## 유지한 영역
Code Destiny 실제 결제 정책·이용권·월정석·단건 결제, 인증, API, DB는 수정하지 않았다. 카페의 기존 저장과 보상 원장, 현재 접대·영입·엔딩 판정 조건을 보존했다. 운세 수첩은 타로·일주·띠·간단 태양 별자리이며 사주 전체·자미두수·베다 명반 구현 완료로 표현하지 않는다.
