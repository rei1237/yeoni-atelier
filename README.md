# 연이의 아틀리에 — 꿀꿀 운세 외전 카페 경영 프로토타입

꿀꿀 운세 세계관의 모바일 세로형 카페 경영 게임 프로토타입이다. 빌드 단계가 없는 ES module 이고 외부 의존성도 없다.

- 지향점: 「용과 같이 0」 물장사 아일랜드식 접대·지명 + 쿠키샵·아이러브커피식 제조·서빙·가게 확장·인테리어 + 뱀파이어 서바이버식 생존 사냥.
- 이야기(게임 오리지널 외전): 재성의 섬 빵집 토끼 자매 루나·루나 언니가 청토끼 금융의 "손님 열 배" 말만 믿고 낡은 카페를 넘겨받았다가 전 주인의 빚 120,000G 까지 떠안았다. 연이와 영냥이(네오)가 가게 일을 도와 빚을 함께 갚는다.
  원작 사실과 이 게임이 정한 설정의 구분은 [docs/WORLD.md](docs/WORLD.md) 에 있다.

- 그림: 아직 이미지 파일이 없다. 32×32 도트 규격의 에셋 자리(`assets/sprites/...`)만 정해 두었고, 파일이 없으면 Canvas 2D 도형으로 대신 그린다.
  도트 이미지는 [docs/ASSETS.md](docs/ASSETS.md) 의 규격·프롬프트대로 만들어 같은 경로에 넣으면 코드 수정 없이 바뀐다.
- 코딩 에이전트(Codex 등) 작업 규칙: [AGENTS.md](AGENTS.md)

## 실행

Node 20 이상(확인한 버전: v24.18.0)이 필요하다.

```bash
npm start
```

브라우저에서 `http://127.0.0.1:5280` 을 연다. 포트는 `PORT` 환경 변수로 바꿀 수 있다.
같은 포트를 다른 프로그램이 쓰고 있으면 서버가 안내 문구를 띄우고 멈춘다.

Windows 에서는 `start.bat` 을 더블클릭해도 된다(서버를 켜고 브라우저를 연다. 창을 닫으면 서버가 꺼진다).
`index.html` 을 직접 열면(file://) 브라우저가 ES module 을 막아서 화면이 나오지 않는다.

- 개발 모드: `http://127.0.0.1:5280/?dev=1`
  - 일반 저장과 다른 키를 쓴다.
  - 배속(1·10·60배), +60초 진행, 개발용 임시 동료 영입 흐름을 쓸 수 있다.
- 테스트: `npm test` (Node 내장 `node:test`)

## 지금 들어 있는 것

- 프롤로그(라이트노벨식 대화 화면)
  - 꿀꿀 운세 라이트노벨의 게임 오리지널 외전이다. 새 게임을 시작하면 재생된다. 타이틀의 "📖 프롤로그 보기" 로 다시 볼 수 있다.
  - 타자 효과, AUTO·SKIP·LOG·이전 대사, 장 제목 카드, 초상화 3칸. 연출은 code-destiny 소설 화면을 참고해 새로 만들었다.
  - 대사는 이 게임의 오리지널 장면이다(원작 EP.01 의 "검은 손" 만 가져왔다).

- 카페 루프
  - 손님 입장 → 주문 → 조리(음료 머신·오븐 각 현재 1 + 다음 1) → 트레이 3칸 → 서빙 → 식사 → 정리
  - 정규 영업은 활성 시간 10분(600초)이다. 일시정지나 탭 숨김 중에는 시간이 흐르지 않는다.
  - 연이는 일하지 않고 입구 옆 계산대에서 계산만 한다. 빚을 진 토끼 자매가 처음부터 돕는다: 루나 언니는 굽기, 루나는 서빙·정리. 네오는 접대만 맡는다.
  - 주방 자동이 기본이다. 주문이 들어오면 루나 언니가 만들고 루나가 서빙·정리한다. 영업 화면의 「🍳 주방」 버튼이나 준비 화면에서 수동으로 바꿀 수 있다.
- 지명
  - 요청 → 수락하면 정확히 60초 동안 네오가 잠긴다 → 만족도 판정·팁 정산.
  - 경과 09:00 까지만 수락할 수 있다. 10:00 에는 남은 접대를 정산한 뒤 마감한다.
- 피버와 자동 운영
  - 피버: 게이지 100을 한 번에 써서 20초 동안 H ≥ 60 테이블 최대 3곳의 팁을 2배로 한다.
  - 전체 자동(🤖): 지명 수락·도움 응답·피버까지 맡긴다. 플레이어와 같은 명령만 쓴다.
- 조합대(레시피 발견)
  - 재료 1~3개를 골라 섞는다. 맞는 조합이면 새 레시피를 배운다(시험으로 섞을 땐 재료가 줄지 않는다).
  - 틀리면 "몇 가지가 겹치는지" 힌트를 준다. 영업 중에 아는 조합을 섞으면 바로 조리를 시작한다.
  - 발견용 임시 메뉴 3종(달빛 밀크티·별가루 카스텔라·꿀꿀 크림 라테)과 밤이슬 라테. 발견 전에는 손님이 주문하지 않는다.
- 영업 밖 활동
  - 영냥이 월정석 사냥(3분, 뱀파이어 서바이버식): 네오와 같은 인물 잠금을 쓴다.
    - 공격은 자동이다. 별조각을 모아 레벨업하면 카드 3장 중 하나를 고른다(고르는 동안 시간이 멈춘다).
    - 무기 5종·보조 능력 6종(모두 임시), 최대 레벨 무기 + 짝 보조 능력 = 진화.
    - 무리·포위·박쥐 떼·엘리트 사건, 2:30 에 보스.
    - 레벨업 곡선이 가파르고, 달이 지날수록 적이 단단해진다(임시 수치, [docs/TUNING.md](docs/TUNING.md)).
    - 적은 재료가 아니라 월정석을 떨어뜨린다(일반 적 6% 확률로 1개, 정예 10개, 보스 60개 · 임시). 쓰러져도 모은 월정석은 가져온다.
  - 인테리어 편집: 영업 전·후에만 할 수 있다.
  - 🏘 마을 나가기(영업 준비 중에만): 계절마다 색이 바뀌는 월드 맵. 장소를 누르면 연이가 그곳으로 가고, 그 장소의 동료와 가게가 아래에 열린다.
    - 모카 식재료점: 수달 모카가 재료를 판다. 영업 중에는 마을에 못 나가고 「모카 긴급 배달」(배달비 붙음)로만 산다.
    - 무인 장비 좌판: 영냥이 무기·방어구·장신구 6종(골드 또는 월정석, 모두 임시). 사냥 능력치만 바뀐다.
    - 루나의 저울: 월정석을 고정 환율로 골드로 바꾼다.
    - 증축 게시판: 테이블 세트(최대 10개, 들일수록 비싸짐)·장식·잠긴 구역 증축(6,000 → 18,000 → 40,000G).
    - 달그늘 사냥터: 영냥이 사냥 출발.
- 달력과 결말(프린세스 메이커식)
  - 영업 1회가 한 순이고 3순이 한 달이다. 1년차 3월 상순에 시작해 2년차 2월 하순(36순)에 청토끼 금융 계약이 만기된다.
  - 하순 영업을 마치면 남은 빚의 2% 가 이자로 나간다. 순마다 행동력 2를 사냥·대화에 쓴다.
  - 매달 상순에 달 이야기가 한 번 나온다. 만기 때 남은 빚과 친밀도로 결말 4가지 중 하나가 정해지고, 그 뒤는 후일담 영업이다.
- 친밀도(인연)
  - 네오·루나·루나 언니·모카와 대화(행동력 1)·선물·함께 일하기로 친밀도를 올린다. 대화·선물은 순마다 한 사람에게 한 번이라 서두를 수 없다.
  - 하트가 한 단계 찰 때마다(4단계) 능력 하나(사냥 HP·보스 월정석·이자 감소·조리 단축·재료 할인·밤이슬 선물 등)와 인연 이야기 한 편이 열린다. 최고 결말은 일만 해서는 닿지 않는다.
  - 능력·이야기·선물은 모두 게임 오리지널 임시 설정이다([docs/WORLD.md](docs/WORLD.md)).
- 경제와 성장
  - 재료 구매(모카), 빚 120,000 상환(청토끼 금융), 데이터 기반 퀘스트, 영입 흐름, 의상(능력치 효과 없음).
- 개그 말풍선
  - 영업 시작·서빙·상환·구매·환전·장비 구입·사냥 복귀·동료와 대화 때 짧은 대사가 뜬다. 화면 연출일 뿐 게임 상태를 바꾸지 않는다. 대사는 [src/data/lines.js](src/data/lines.js).
- 저장
  - 이어하기, 자동 저장, 저장 초기화(확인 필요).
  - 오프라인 수익은 인터페이스와 저장 칸만 있고, 골드는 지급하지 않는다.

새 게임의 접대 담당은 **네오 한 명**이다. 다른 데스티노바 멤버는 공식 자료가 없어서 만들지 않았다. 대신 "새로운 인연" 잠금 칸만 둔다.

시작 가게는 2인 테이블 세트 5개다. 6번째부터 2,500G로 시작해 구매가가 증가한다(임시). 기존 저장의 가구·구매 내역은 유지한다.
