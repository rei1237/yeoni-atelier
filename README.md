# 연이의 아틀리에
Code Destiny 세계관의 모바일 세로형 카페·농장·생존 사냥 게임. Canvas 2D와 ES modules로 실행한다. 원작 사실과 게임 오리지널 설정은 [WORLD](docs/WORLD.md)에서 구분한다.

## 실행
Node 20 이상에서 `npm start` 후 http://127.0.0.1:5280 을 연다. Windows에서는 start.bat도 사용할 수 있다. file:// 실행은 지원하지 않는다. PORT 환경 변수로 포트를 바꿀 수 있다.

- 일반 플레이: 수동 조리가 기본. 영업 1·2·3배속.
- 개발 플레이: /?dev=1. 일반 저장과 분리된 키, 개발 자동화·배속.
- 검증: `npm test`, `node tools/check-assets.mjs`. 별도 빌드·런타임 패키지 없음.

## 운영과 이야기
소박한 동네 카페로 시작한다. 3·4월에는 기본 메뉴를 주로 만들고, 5월 「오늘부터 호스트 카페!」 이벤트 후 지명이 열린다. 영업 한 번은 게임 시간 10분, 모든 접대는 60초다. 3순이 한 달, 180순인 5년 운영 후 결말을 맞는다.

- 손님별 주문 카드: 자리 안내 → 메뉴 고르는 중 → 실제 주문 메뉴 → 조리·운반 → 식사 → 연이에게 계산. 빈 트레이를 주문처럼 표시하지 않는다.
- 수동 조리: 메뉴를 눌러 재료 담기·섞기·마무리 3단계. 마지막 단계에서만 재료를 쓰고 완성 효과를 보여 준다. 주방 자동은 선택이며 수동 전환 시 전체 자동도 해제한다.
- 루나 언니는 주방, 루나는 홀, 연이는 계산대, 네오와 합류한 동료는 접대를 맡는다. 이동 방향에 맞춰 걷고 트레이에 해당 주문 음식 그림을 얹는다. 정리할 때 청소 소품을 쓴다.
- 검소·평범·통 큰·대부호 손님, 포장 주문, 지명 팁과 피버, 인기 변화와 입소문 대사. 포장은 테이블 서빙 없이 계산대로 간다.
- 카페 레벨과 분위기가 방문 빈도·손님 등급·메뉴 가격에 영향을 준다. 최대 24테이블, 20×24 구역까지 증축한다.
- 최고급 운명의 찻집 메뉴는 깊은 사냥에서 얻은 재료로 만든다. 조리는 지명 여부와 관계없이 가능하며, 판매는 지명 접대를 수락한 손님에게만 한다.

## 동료와 드레스룸
윤달·무성·모카·서한비와 데스티노바의 개별 프로필·능력·이야기, 네오와의 인연을 통한 합류를 제공한다. 모카는 여성 수달이다. 서한비는 사용자 확정의 검은 드레스 여성/검은 호랑이이며 영입 전 ?와 실루엣만 보인다. 다섯 숨은 조건을 충족해야 영입할 수 있다.

인연 대화는 선택에 따라 +12/+6/+2로 달라지고 단계별 능력을 연다. 남성 호스트 드레스룸은 네오·윤달·무성·데스티노바 멤버의 평상복·무대복·연미복·수영복, 설명·네 방향 미리보기를 제공한다. 카페에도 적용하며 의상은 외형·대사 전용이다.

## 농장·사냥·마을
- 꽃돼지 연이의 씨앗·물·돌봄·수확. 날씨·계절·온실·농장 레벨과 요리 재료 생산.
- 사냥은 시간 제한 없이 쓰러지거나 직접 돌아올 때까지 진행한다. 영냥이와 영입한 서한비 중 선택하며, 지속 성장과 탐사 중 레벨업은 별개다.
- 100단계: 35단계 청토끼, 55단계 강화 청토끼, 85단계 흑월의 파편. 시간이 지날수록 강해지는 적과 필드 수집 외 생존 월정석·재료 보상.
- 모카: 식재료·긴급 배달·무기·개별 영구 강화·회복 소모품. 친밀도에 따라 판매 품목이 늘어난다. 강화는 레벨 상한 없이 점차 비싸진다.
- 청토끼 금융 센터: 환전·운영 대출·골드/월정석 상환. 새 게임 인수 빚 99,999,999G. 기존 저장의 빚은 보존한다. 네오·루나 자매는 무급, 새 접대 동료는 월급을 받는다.
- 빚을 다 갚고 큰 부를 쌓으면 청토끼를 직원으로 영입할 수 있다. 외모는 낮고 화술은 높으며 접대 수입에 보너스를 준다. 게임 오리지널 후일담이다.

## 그림·소리·문서
사용자 프로필을 기준으로 투명 일러스트 스프라이트, 정적 라이트노벨 초상화, 담당 캐릭터 안내 그림과 튜토리얼을 사용한다. 340개 에셋 키를 검사한다. 일부 기존 적·타일·UI는 재사용하며 여섯 희귀 재료의 개별 아이콘은 색상 대체다. OST 네 곡은 공식 공개 스트리밍으로 재생하고 처음에는 꺼져 있다. 음악·효과음을 따로 조절한다. 기기에 설치된 한국어 시스템 글꼴을 사용한다.
