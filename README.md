# 연이의 아틀리에 — 1단계 기반 프로토타입

꿀꿀 운세 세계관의 모바일 세로형 카페 경영 게임 프로토타입이다. 빌드 단계가 없는 ES module 이고 외부 의존성도 없다.

- 그림: 아직 이미지 파일이 없다. 32×32 도트 규격의 에셋 자리(`assets/sprites/...`)만 정해 두었고, 파일이 없으면 Canvas 2D 도형으로 대신 그린다.
  도트 이미지는 [docs/ASSETS.md](docs/ASSETS.md) 의 규격·프롬프트대로 만들어 같은 경로에 넣으면 코드 수정 없이 바뀐다.
- 코딩 에이전트(Codex 등) 작업 규칙: [AGENTS.md](AGENTS.md)

## 실행

Node 20 이상(확인한 버전: v24.18.0)이 필요하다.

```bash
npm start
```

브라우저에서 `http://127.0.0.1:5280` 을 연다. 포트는 `PORT` 환경 변수로 바꿀 수 있다.
같은 포트를 다른 프로그램이 쓰고 있으면 서버가 안내 문구를 띄우고 멈춘다.

Windows 에서는 `start.bat` 을 더블클릭해도 된다(서버를 켜고 브라우저를 연다. 창을 닫으면 서버가 꺼진다).
`index.html` 을 직접 열면(file://) 브라우저가 ES module 을 막아서 화면이 나오지 않는다.

- 개발 모드: `http://127.0.0.1:5280/?dev=1`
  - 일반 저장과 다른 키를 쓴다.
  - 배속(1·10·60배), +60초 진행, 개발용 임시 동료 영입 흐름을 쓸 수 있다.
- 테스트: `npm test` (Node 내장 `node:test`)

## 1단계 범위 요약

- 프롤로그(라이트노벨식 대화 화면)
  - 새 게임을 시작하면 재생된다. 타이틀의 "📖 프롤로그 보기" 로 다시 볼 수 있다.
  - 타자 효과, AUTO·SKIP·LOG·이전 대사, 장 제목 카드, 초상화 3칸. 연출은 code-destiny 소설 화면을 참고해 새로 만들었다.
  - 대사는 이 게임의 오리지널 장면이다(원작 EP.01 의 "검은 손" 만 가져왔다).

- 카페 루프
  - 손님 입장 → 주문 → 조리(음료 머신·오븐 각 현재 1 + 다음 1) → 트레이 3칸 → 서빙 → 식사 → 정리
  - 정규 영업은 활성 시간 30분(1,800초)이다. 일시정지나 탭 숨김 중에는 시간이 흐르지 않는다.
- 지명
  - 요청 → 수락하면 정확히 300초 동안 네오가 잠긴다 → 만족도 판정·팁 정산.
  - 경과 25:00 까지만 수락할 수 있다. 30:00 에는 남은 접대를 정산한 뒤 마감한다.
- 피버와 자동 운영
  - 피버: 게이지 100을 한 번에 써서 20초 동안 H ≥ 60 테이블 최대 3곳의 팁을 2배로 한다.
  - 자동 운영: 플레이어와 같은 명령만 쓴다.
- 조합대(레시피 발견)
  - 재료 1~3개를 골라 섞는다. 맞는 조합이면 새 레시피를 배운다(시험으로 섞을 땐 재료가 줄지 않는다).
  - 틀리면 "몇 가지가 겹치는지" 힌트를 준다. 영업 중에 아는 조합을 섞으면 바로 조리를 시작한다.
  - 발견용 임시 메뉴 3종(달빛 밀크티·별가루 카스텔라·꿀꿀 크림 라테)과 밤이슬 라테. 발견 전에는 손님이 주문하지 않는다.
- 영업 밖 활동
  - 영냥이 재료 탐색(3분, 뱀파이어 서바이버식): 네오와 같은 인물 잠금을 쓴다.
    - 공격은 자동이다. 별조각을 모아 레벨업하면 카드 3장 중 하나를 고른다(고르는 동안 시간이 멈춘다).
    - 무기 5종·보조 능력 6종(모두 임시), 최대 레벨 무기 + 짝 보조 능력 = 진화.
    - 무리·포위·박쥐 떼·엘리트 사건, 2:30 에 보스. 쓰러져도 모은 재료는 가져온다.
  - 인테리어 편집: 영업 전·후에만 할 수 있다.
- 경제와 성장
  - 재료 구매, 빚 120,000 상환, 데이터 기반 퀘스트, 영입 흐름, 의상(능력치 효과 없음).
- 저장
  - 이어하기, 자동 저장, 저장 초기화(확인 필요).
  - 오프라인 수익은 인터페이스와 저장 칸만 있고, 골드는 지급하지 않는다.

새 게임의 접대 담당은 **네오 한 명**이다. 다른 데스티노바 멤버는 공식 자료가 없어서 만들지 않았다. 대신 "새로운 인연" 잠금 칸만 둔다.
